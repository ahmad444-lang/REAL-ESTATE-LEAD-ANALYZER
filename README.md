# REAL-ESTATE-LEAD-ANALYZER
AI Lead Qualifier 🤖 n8n workflow that automates lead scoring using Gemini AI.  📝 Capture: Leads from Tally.so via Webhooks.  🧠 AI Score: Gemini scores intent (1-10) based on budget/plan.  📈 Database: Auto-logs data to Google Sheets.  📧 Alerts: Gmail notifications for Hot Leads (Score 8+).  Efficient, real-time, and 100% automated.
